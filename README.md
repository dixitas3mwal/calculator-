# Calculator App 

A responsive calculator built using HTML, CSS, and JavaScript.

## Features

* Addition, subtraction, multiplication, and division
* Responsive design
* Modern dark theme
* Interactive button animations
* Error handling for invalid expressions

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Purpose

This project was created to strengthen my understanding of front-end web development. It demonstrates the use of HTML for structure, CSS for styling, and JavaScript for interactive functionality.

## Future Improvements

* Scientific calculator functions
* Keyboard support
* Calculation history
* Light/Dark mode toggle
